How optimized B works

S1
Stage 1 — BPE base (~2500 slots)

Same engine as Approach A (ClassicBPE): pair merges inside pretok words. Train knob en_merge_weight=2.0 upweights EN unit frequencies during merge counting. Result: 2297 merges, base vocab ≈ 2500 (chars + merges).

S2
Stage 2 — whole-word fill (rest → 10k)

Rank types by token savings: score(w) = Σ_L α_L · freq_L(w) · max(0, pieces_bpe(w) − 1) with α_L = 1 for all languages. Insert highest scores until vocab is full → ~7500 whole words added.

ENC
Encode — DP min-cover

Pretokenize with WORD_RE. If the whole unit is in vocab → 1 token; else find the fewest-character partition using vocab pieces (encode_mode=dp).
