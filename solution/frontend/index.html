01 · The brief

The assignment

Train one tokenizer that treats four languages fairly. Fertility X_L = tokens(L) / faithful_units(L) — a faithful unit is one contiguous letter/mark/number run, or one visible punctuation/symbol character.

score = 1000 / (X₄ − X₁)   // X₄ = max fertility, X₁ = min
  • ✓ Vocabulary must be exactly 10000
  • ✓ Every X_L ≤ 1.2
  • ✓ decode(encode(text)) preserves visible characters
  • ✓ 0 UNK tokens
  • ✓ English penalty: score / exp(max(0, X_EN/1.2 − 1))

Tighter fertility spread across languages → higher score. Fairness, quantified.

02 · Rock bottom

We scored zero.

Our first submission was word-level with a fixed word vocabulary. One innocent sentence killed it on the faithfulness gate:

India's population is 1,428,627,663.
→ India <UNK> s population is <UNK> .

Any token not in the word vocabulary became <UNK> — an instant fail. The fix: a byte-level base. 256 byte symbols cover every possible UTF-8 input, so any text decodes byte-exact and UNK becomes structurally impossible.

  • ✗ Word-level: unseen word → <UNK> → score 0
  • ✓ Byte-level: every input is a sequence of known bytes → 0 UNK, lossless, forever
03 · The engine

Hand-written BPE.
Max-heap fast.

No tokenizer libraries. The BPE trainer is written from scratch: GPT-2-style reversible byte↔unicode map, cross-word line-level merges, and an incremental max-heap of pair frequencies with lazy invalidation — pop the true most-frequent pair in O(log n) instead of rescanning every pair each merge.

  • ✓ 256 byte symbols + 4 specials as the base alphabet
  • ✓ Heap-backed pair selection → production-grade training speed
  • ✓ 9740 merges learned to land vocab at exactly 10000
  • ✓ encode() applies merges by rank; decode() maps bytes back — byte-exact

07 · The insight

The corpus was polluted.

After comparing our dataset with the instructor's dataset, we realized ours was polluted — scraped Indic pages full of percent-encoded URL hex and other noise that BPE happily compressed into oblivion. The tokenizer wasn't learning language; it was learning garbage.

%E0%A4%B8%E0%A4%82%E0%A4%B8%E0%A5%8D%E0%A4%95%E0%A5%83%E0%A4%A4 …

The move: switch to the instructor's dataset and retrain on clean, comparable text for every language. Same languages, real prose, fair comparison.
